# Modiseh Landing Page

A simple and responsive landing page designed using **HTML**, **CSS**, and **Bootstrap**. This project aims to provide a clean, modern design for showcasing information with no JavaScript.

---

## Technologies & Tools

- HTML
- CSS
- Bootstrap (for responsive design)

## Getting Started (Local Setup)

1. Clone the repository:

```bash
git clone https://github.com/zeinabhoma/Modiseh-sample-project.git


```

2. Navigate to the project folder and install dependencies:

```bash
cd Modiseh-sample-project
```

##  Features

-Simple, clean design using Bootstrap
-Fully responsive layout (works on mobile, tablet, and desktop)
